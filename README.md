## Introduction

This repository contains the data, scripts, and Jupyter notebooks used to generate the results presented in our paper
**"Development of a Variational Quantum Algorithm for Measurement Reduction via the Block-Encoding Method."**
We publish this repository to support the reproducibility of our results.

This document provides an overview of the repository structure and instructions on how to use the materials.
Please read it carefully before attempting to reproduce the results.

## Requirements

The code was tested with **Python 3.11**. Required packages can be installed with:

```bash
python3.11 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

In addition, two external repositories must be cloned into `vendor/` (see [vendor](#vendor)).

## data

- `npz`: numerical simulation results.
- `pdf`: figures reproduced by the notebooks.
- `rhf`: molecular Hamiltonians in FCIDUMP format, required by both scripts and notebooks.
- `txt`: logs describing the simulation conditions and results.

In both `npz` and `txt`, two subdirectories are used:

- `for_paper`: the exact data used to generate the figures in the manuscript.
- `worked`: results generated by users running the provided scripts. Each run is stored in a subdirectory named by its time stamp.

### Contents of the NPZ files

The keys `array1` and `array2` have the same meaning in `for_paper` and `worked`, and they are the only keys used by the notebooks. The remaining keys differ between the two sets because the output format of the scripts was reorganized for this public release.

| Method | Key | `for_paper` | `worked` |
| --- | --- | --- | --- |
| VEBE | `array1` | sampled estimates $-S'\sqrt{p_\mathrm{succ}}$ (per set) | same |
| VEBE | `array2` | final shift value $\gamma + \delta$ | same |
| VEBE | `array3`– | bond length, exact $p_\mathrm{succ}$, $S'$, and auxiliary data | exact $p_\mathrm{succ}$ (`array3`), estimated $p_\mathrm{succ}$ per set (`array4`) |
| VQE | `array1` | sampling results for each set and Pauli term: (sampled probability, sampled expectation, exact probability, exact expectation) | same |
| VQE | `array2`– | exact ground-state energy and auxiliary data | bond length (`array2`) |

## notebook

The notebooks reproduce the figures listed above. Select the data set with `DATA_SOURCE = "for_paper"` (default) or `"worked"` in the settings cell.
The external repositories in `vendor/` must be cloned before running the notebooks.

## scripts

The scripts perform the quantum-circuit simulations and save the results in `data/npz/worked` and `data/txt/worked`.
Run them from the `scripts/` directory, for example:

```bash
cd scripts
python3 simulation_for_vebe_by_fci.py
```

Settings that must be edited for each run are marked in the scripts:

- the molecule (`"H2"`, `"H4"`, `"H6"`) and, for the approximate shift, the number of electrons;
- `shift_type = "exact"` or `"approximate"`;
- for the optimization scripts, the random seeds (H$_2$: 0–99; H$_4$: 100).

Simulations of larger systems (H$_6$ and N$_2$) require substantial memory and computing time.

## vendor

This directory contains external repositories used by the scripts and notebooks. They are **not authored** by the authors of this project and are not tracked in this repository.

- [`PItBE`](https://github.com/B-REO/PItBE): library for block-encoding-based quantum simulations.
- [`quantum_software_handson`](https://github.com/Qulacs-Osaka/quantum_software_handson): utility library including `qchem_util.py`, used to read FCIDUMP files.

Clone them as follows. The commits listed below are those used to generate the results in the manuscript.

```bash
git clone https://github.com/B-REO/PItBE.git vendor/PItBE
git -C vendor/PItBE checkout <COMMIT_HASH_PITBE>

git clone https://github.com/Qulacs-Osaka/quantum_software_handson.git vendor/quantum_software_handson
git -C vendor/quantum_software_handson checkout <COMMIT_HASH_QSH>
```
